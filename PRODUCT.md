# Product

## Register

product

## Users

Working voiceover actors preparing scripts, estimating timing, and generating client quotes. They open Script Analysis mid-workflow: before an audition, while scoping a project, or reviewing revisions against an original. Speed and accuracy matter; they want numbers fast and a quote they can send.

## Product Purpose

VO Tools provides professional-grade utilities for voice actors and audio engineers. Script Analysis is the flagship tool: paste a script, get word count, timing at adjustable WPM, pause detection, and a pricing calculator that exports PDF quotes. Secondary tools handle telephony audio conversion and teleprompter sessions; delivery-spec checks (ACX and others) link out to Spec Check.

## Brand Personality

Professional, efficient, trustworthy. The tool earns trust by being fast, accurate, and visually calm. No hype, no cleverness for its own sake. Think Stripe's clarity or Linear's restraint applied to a creative-industry utility.

## Anti-references

- Generic SaaS dashboards: no cookie-cutter metric cards, gradient hero numbers, or startup-template aesthetics.
- Cluttered pro-audio tools: no intimidating walls of knobs and controls (Pro Tools, Audacity). The interface should feel like a focused writing tool, not a mixing console.
- Overdesigned creative-agency sites: no parallax storytelling or decorative motion that slows down a working professional.

## Design Principles

1. **Numbers first**: The primary output is quantitative (word count, time, price). Surface these with maximum clarity and minimum decoration.
2. **Paste and go**: The tool should feel instant. No onboarding, no setup wizard, no account. Paste script, read results.
3. **Progressive disclosure**: Show the essential analysis immediately; let users opt into pricing, expansion settings, and comparison mode when they need them.
4. **Quiet confidence**: Professional tools earn trust through restraint, not flash. Calm surfaces, clear type, purposeful color.
5. **Respect the workflow**: Voice actors use this mid-task. Don't interrupt their flow with modals, tooltips, or unnecessary confirmations.

## Accessibility & Inclusion

WCAG AA baseline. Standard contrast ratios, keyboard navigation, screen reader support for all interactive controls. Respect prefers-reduced-motion.
